## 项目一句话定位

面向社区杂货铺（便利店 / 日用百货 / 小型超市）的私域数字化经营系统：顾客在微信小程序完成「浏览—下单—支付—自提/配送」，店主在 Web 后台完成商品、订单、会员与营销管理。

## 技术栈约束（必须遵守）

| 端 | 技术选型 | 约束 |
|----|----------|------|
| 顾客端 | **微信小程序原生**（WXML / WXSS / JS 或 TS / JSON） | 不使用 uni-app、Taro 等跨端框架 |
| 管理端 | **Vite 4.x + TypeScript + React 18 + Material UI v5** | **运行与构建环境必须适配 Node.js 16.17.0**（不可使用 Vite 5+/MUI v6 作为默认栈） |
| 服务端 | Node.js 16.17.0 + Express（或 Koa）+ TypeScript | 与管理端同一 Node 大版本，降低运维复杂度 |
| 支付 / 消息 | 微信支付、微信订阅消息 | 按微信官方能力接入 |

详细版本锁定见 [技术架构与技术方案](./04-技术架构与技术方案.md) 第 3 章。

## 适用经营主体

- SKU 约 200 以内、月营收 50 万以下的社区小店
- 服务半径约 1–3 公里，履约以到店自提为主、店主配送为辅
