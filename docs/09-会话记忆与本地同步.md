## 1. 对话里拍板的约束（必须遵守）

- 顾客端：**微信原生小程序**（WXML/WXSS/TS），禁止 uni-app / Taro。
- 管理端：**Vite 4.5.x + React 18.2 + TypeScript 5.3.3 + MUI v5.15**，禁止默认 Vite 5+ / MUI v6。
- 运行时：**Node.js 16.17.0**；服务端 Express 4 + knex + mysql2。
- 本机数据库：**MySQL 8**，`127.0.0.1:3306`，账号 `root` / `root`。
- 金额存 **分**；下单金额服务端重算。
- 订单 **预占库存**（`WHERE stock >= qty` 条件更新），禁止无事务先读后写。
- 购买率以 **支付成功（回调 / 模拟支付）** 为准，不信客户端。
- 多门店仍不做。M6（正式域名/审核/支付进件）置后。
- 已做：优惠券、特价、积分、库存预警、订阅消息记录、拼团、秒杀、个性化推荐、详情关联、购物车凑单。
- 推荐 = **置顶 + 热度补齐**（`PIN_THEN_HEAT`），不上推荐模型。
- **P0 埋点必须跟交易域一起上**，不能等到运营看板。
- 开发可用 `MOCK_WX=true`、`MOCK_PAY=true`；正式上线必须关掉。
- 小程序 AppID：`wx6434c5c04d4b6c6e`（已写入 `miniprogram/project.config.json`）。体验版二维码须在微信开发者工具上传后于公众平台生成。

## 5. 关键业务口径

- 订单状态：`PENDING_PAY` → 支付成功 `PENDING_PACK` → 自提 `WAIT_PICKUP` 核销完成 / 配送 `WAIT_DELIVER` → `DELIVERING` → `COMPLETED`；取消回库存。
- 提货码：6 位，`100000–999999`；错误码业务码 `10004`。
- 暂停接单：浏览可以，下单 409 / `10005`。
- CTR = click_uv / expose_uv；CVR = pay_uv / click_uv；样本不足展示「— / 样本少」。
- 热度 0–100，**不含**人工加权；`rank_score = heat + manual_weight`；售罄沉底；上架 72h 排序 +8。
- 推荐位 `home_recommend`：售罄置顶跳过。
- 事件单包 ≤20 条；不落 openid/手机号。
- 管理端默认 `admin` / `admin123`。
- 开发库 `variety_shop`，测试库 `variety_shop_test`（单测不写开发库）。

## 6. 本机同步与建库（Windows）

在 **PowerShell 或 cmd**（本机，不是云端）执行：

```bat
cd /d D:\project-code\project-code\my-cursor-project\wechat-mini-program-variety-shop

git remote -v
git fetch origin
git checkout cursor/implement-r1-r2-2abd
git pull origin cursor/implement-r1-r2-2abd

copy /Y .env.example .env

mysql -h127.0.0.1 -P3306 -uroot -proot --default-character-set=utf8mb4 < scripts\variety_shop.sql
```

若该目录还不是 git 仓库：

```bat
mkdir D:\project-code\project-code\my-cursor-project\wechat-mini-program-variety-shop
cd /d D:\project-code\project-code\my-cursor-project\wechat-mini-program-variety-shop
git clone https://github.com/zss520/wechat-mini-program-variety-shop.git .
git checkout cursor/implement-r1-r2-2abd
copy /Y .env.example .env
mysql -h127.0.0.1 -P3306 -uroot -proot --default-character-set=utf8mb4 < scripts\variety_shop.sql
```

也可双击仓库内 `scripts\sync-local-windows.cmd`（已写死上述路径）。

导入后本机客户端刷新，应看到 **variety_shop** 共 18 张表。验证：

```bat
mysql -h127.0.0.1 -P3306 -uroot -proot -e "USE variety_shop; SHOW TABLES; SELECT COUNT(*) FROM goods;"
```

本机需已安装并启动 MySQL 8，且 `mysql.exe` 在 PATH 中。Node 请用 **16.17.0**（见 `.nvmrc`）。

```bat
cd server && npm install && npm run dev
cd admin && npm install && npm run dev
```

微信开发者工具导入本仓库的 `miniprogram\` 目录。
